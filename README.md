# Projet 13 – Créez votre portfolio de professionnel de la data

## 🎯 Objectif

Concevoir un portfolio professionnel permettant de valoriser les compétences acquises au cours de la formation Data Analyst et de présenter ses réalisations à des recruteurs ou clients potentiels.

## 📌 Contexte

Projet réalisé dans le cadre de la formation **Data Analyst – OpenClassrooms**.

Ce projet de fin de parcours vise à rassembler les différents projets réalisés durant la formation dans un portfolio structuré, accessible et orienté métier.

## ❓ Problématique

Comment présenter efficacement ses compétences, ses projets et son expertise afin de démontrer sa capacité à répondre à des problématiques Data en environnement professionnel ?

## 🛠️ Approche & outils

* Sélection des projets les plus représentatifs
* Structuration du portfolio
* Mise en valeur des compétences techniques et métier
* Création de tableaux de bord de présentation
* Documentation des projets sur GitHub

Outils utilisés :

* Power BI
* GitHub
* Markdown
* Excel

## 📊 Résultats & livrables

Le projet aboutit à :

* Un portfolio professionnel présentant le parcours et les compétences
* Une centralisation des projets réalisés durant la formation
* Une présentation synthétique des réalisations Data
* Une documentation facilitant la consultation des projets

L'ensemble des livrables est disponible dans le dossier `livrables/`.

## ✅ Compétences mobilisées

* Gestion de projet Data
* Data Visualisation
* Storytelling
* Communication professionnelle
* Documentation technique
* Valorisation de projets Data
* Présentation de résultats à des publics non techniques
